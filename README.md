# ProjectHalf: Volunteering Management App 📱

**ProjectHalf** is a cross-platform mobile application built using **Flutter** as part of a university semester project. The application is designed to streamline and manage volunteering activities for students, non-profit organizations, and academic institutions. 

By centralizing the process of discovering, organizing, and tracking volunteer opportunities, **ProjectHalf** promotes community engagement and social responsibility in a modern, mobile-first way.

---

## 🧭 Project Objectives

- Enable students to discover and register for volunteer opportunities
- Provide non-profit organizations with tools to create and manage events
- Allow university administrators to track student engagement and generate reports
- Ensure smooth coordination and communication between all users

---

## ✨ Key Features

- 🔍 **Explore Volunteer Events**  
  Discover opportunities by category, location, or date

- 📝 **One-Click Registration**  
  Sign up for events through an intuitive UI

- 🔔 **Push Notifications**  
  Get real-time alerts about upcoming events or changes

- 📈 **Track Hours and Participation**  
  View and export history of participation and logged hours

- 🛠️ **Organizer Dashboard**  
  Event creation, updates, and participant management
